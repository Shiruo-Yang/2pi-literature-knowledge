# 双光子光引发剂文献知识数据库

本项目公开一套已经合并整理的双光子光引发剂文献知识数据库。数据库把文献来源、结构化证据、领域规则、分子身份、模型记录、筛选记录和量子化学证据放在同一个项目中管理，但不同科学用途仍使用独立的数据表，避免把文献描述、模型预测和实验事实混为一谈。

当前公开快照日期为2026年9月6日。对外只维护一套“当前数据库”，不再把内部处理批次作为并列数据库名称。历史中间表只保存在审计目录中，用于追溯数据如何形成。

## 当前数据库包含什么

文献与知识层目前包括：

- 345篇已登记来源文献；
- 9,107条自动提取的字段候选；
- 8,573个经过归一化整理的证据组；
- 25条领域先验规则；
- 25条光引发机理规则；
- 19条合成路线证据；
- 六项分子性质的定义、标签处理方法、任务权重和模型使用记录。

来源内分子身份数据库目前包括：

- 124个来源内标签实体；
- 3,376条实体—文献证据链接；
- 2,344个条件或配方候选簇；
- 72条通过结构检查的单分子身份；
- 8条单独保存的盐、离子材料或商业多组分材料记录；
- 13条被确认不是分子身份的缩写或标记；
- 31条仍缺少唯一结构对应关系的待处理记录。

72条身份表示72个“文献来源—化合物标签”的可靠对应关系，不等同于72种互不重复的新化合物。相同化合物在不同论文中出现时，仍分别保留来源关系，以保证追溯性。

## 文件形式

数据库同时提供三种主要形式：

- CSV：可直接用Excel打开，适合阅读、筛选、核查和作为论文补充表；
- SQLite：适合程序查询、表间关联和完整数据库冻结；
- JSON或JSONL：适合保存机器提取结果、运行摘要和自动化流程交换。

当前分子身份主表位于 `outputs/literature_identity_current/`。其中：

- `accepted_source_identity_registry.csv`保存通过检查的单分子身份；
- `multicomponent_material_registry.csv`保存盐、离子材料和商业多组分材料；
- `terminal_identity_registry.csv`保存不应继续当作单分子处理的终止分类；
- `formulation_linkage_registry_enriched.csv`保存文献条件、配方与可确认分子身份之间的联系；
- `condition_identity_linkage.sqlite`提供可直接查询的整合数据库；
- `unresolved_queue/`保存尚不能唯一确定结构的记录；
- `audit/`只保存历史中间表，不作为当前主数据库。

完整目录关系见 `DATABASE_MAP.md`。

## MinerU.Chem的作用

MinerU.Chem只是文献解析工具，用于识别页面文字、结构图、化合物编号、表格、反应图、页码和版面位置。它的输出首先是候选证据，不会因为“成功识别”就自动成为数据库事实。

候选结构只有在化合物编号、结构图位置、不同图像分辨率下的识别结果、来源文字定义以及标准分子标识能够相互一致时，才进入接受身份表。盐、多组分材料、结构竞争、编号不能唯一对应或来源信息不足的记录会被分离保存。

MinerU.Chem不会改变六项预测任务、任务权重、图神经网络、ZINC22筛选规则或量子化学结论，也不会自动生成实验数值。

## 科学边界

文献身份数据库解决的是“论文中的名称或编号究竟对应哪个分子”以及“证据来自哪里”。它不等于实验光学数据库，也不会自动创建最大双光子吸收截面、聚合阈值、毒性、溶解度或量子化学标签。

模型训练数据、独立外部验证数据、ZINC22筛选结果和量子化学结果仍按各自的数据质量门管理。只有明确记录结构、数值、单位、实验条件和文献来源的数据，才可能进入相应的实验或模型数据层。

## 完整性与公开边界

公开包提供文件哈希、数据库清单和自动发布检查。当前72条单分子结构均可由RDKit解析并重新计算标准结构标识；SQLite完整性检查通过。

公开仓库不包含本地PDF、文献页面图像、私人缓存、账号信息或本机绝对路径。文献页码和来源位置作为追溯字段保留，但受版权保护的全文不在仓库中重新分发。
